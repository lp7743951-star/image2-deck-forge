# Terminal Tech Magazine

## Identity

A restrained technical magazine rendered as a living terminal: dark, precise, modular, and credible.

## Use

Best for AI systems, developer tools, product architecture, technical workflows, reliability, security, and infrastructure. Avoid lifestyle, fashion, and nature-led narratives.

## Visual DNA

- Typography: modern grotesk sans for titles; compact monospace for labels and annotations.
- Palette: near-black `#020708`, ink-green `#061112`, signal mint `#20F5D0`, electric cyan `#5FEAFF`, cool white `#F4F8F8`, steel gray `#AAB7BC`, warning amber `#FFCC66`.
- Grid: 12-column technical grid with generous outer safe area and obvious alignment.
- Containers and borders: dark glass or terminal panels, 1-2 px internal rules, 6-16 px radius; never draw a full-slide perimeter frame.
- Text density: low; one claim, one support line, and at most three compact signals.
- Image direction: system diagrams, machines, technical macro photography, controlled industrial scenes.
- Negative rules: no neon overload, no purple-dominant cyberpunk, no game UI, no dense dashboard, no decorative code walls, no full outer border.

## Style Lock

Keep black terminal surfaces, mint/cyan signal color, sparse internal HUD geometry, strong hierarchy, and one visual anchor on every slide. Typography, palette, grid, containers, text density, image direction, and negative rules must remain stable across the deck.

## Page Behavior

- Cover: oversized claim with one terminal or technical object.
- Narrative: one dominant visual plus two or three compact system signals.
- Comparison: paired dark panels with a single bright distinction.
- Metrics: large numeric type, minimal supporting labels, no dashboard clutter.
- Closing: one decisive claim and a calm terminal cursor or signal motif.

## Prompt Prefix

Create a premium 16:9 technical editorial slide on a near-black terminal field. Use sparse mint and cyan signals, cool-white typography, a disciplined grid, one meaningful technical image or diagram, and no full-slide border. Keep text short, crisp, and highly legible.

## Quality Gate

Confirm the slide reads at thumbnail size, contains no clipped text, uses no full-slide frame, avoids cyberpunk noise, and still looks like the same technical magazine as the previous slide.
